# 🏝️ 가족 섬 만들기 (Make Family Island) — 게임 기획서 v0.1

> 4인 가족(부모 + 아이 2)이 함께, 또는 각자 즐기는 협동형 섬 개척 게임
> 플랫폼: HTML5 (Canvas 2D 도트) · 모바일/태블릿 브라우저

---

## 1. 기획 의도

| 가족 구성원 | 좋아하는 게임 | 원하는 재미 |
|---|---|---|
| 아이들 | 마인크래프트, 로블록스 | 탐험, 채광, 전투, 건축, 함께 놀기 |
| 엄마 | 모여봐요 동물의 숲, 머지 게임 | 아기자기한 꾸미기, 수집, 합치기 |
| 아빠 | (개발자) | 가족이 같이 즐기는 것 |

**핵심 원칙**
1. **역할 고정 없음** — 누구나 모든 활동을 할 수 있다. 한 명이 빠져도 진행이 멈추지 않는다.
2. **혼자 해도 진행, 같이 하면 더 즐겁게** — 협동은 보너스이지 필수 조건이 아니다.
3. **실패·페널티 없음** — 아이들이 좌절하지 않도록 잃는 것이 없다.
4. **가족의 흔적이 섬에 남는다** — 누가 무엇을 했는지 보이게 한다.

---

## 2. 컨셉 / 세계관

가족이 무인도에 표류한다. 처음엔 텐트 하나와 모닥불뿐.
섬을 탐험하며 **사냥 · 채집 · 광물 캐기**로 재료를 모으고, **머지**로 가공해 마을을 짓고, 동물 주민을 맞이해 **"우리 가족 마을"**을 완성한다.

- 시작 시 섬 이름, 가족 캐릭터(도트 아바타) 직접 설정

---

## 3. 핵심 루프

```
탐험 활동 (사냥·채집·채광)
      ↓
  공용 창고
      ↓
 머지로 가공 (재료 → 가구/건물 부품/도구)
      ↓
 짓기 · 꾸미기
      ↓
 주민 입주 · 마을 레벨업
      ↓
 새 지역 · 새 도구 해금 ──→ 다시 탐험
```

**화면 구성 (탭 3개, 누구나 자유 이동)**
- 🗺️ **탐험** — 탑다운 도트 맵, 활동 수행
- 🧩 **머지** — 합치기 보드
- 🏝️ **꾸미기** — 섬 전체 맵에서 배치

---

## 4. 탐험 활동

### 4.1 🌿 채집
- **도구**: 맨손 → 바구니(채집량 증가)
- **행동**: 나무 흔들기, 꽃 따기, 열매·버섯 줍기
- **획득**: 나뭇가지, 꽃, 꽃씨, 사과, 버섯
- **특징**: 가장 쉬운 활동. 하루 지나면 리젠

### 4.2 ⛏️ 광물 캐기
- **도구**: 나무 → 돌 → 철 → 보석 곡괭이
- **행동**: 바위/동굴 벽을 여러 번 탭해서 깨기 (도구 등급이 높을수록 탭 수 감소)
- **획득**: 돌, 석탄, 구리, 철, 보석(희귀)
- **특징**: 동굴은 층(Floor) 구조, 깊을수록 좋은 광석. 가끔 "반짝이는 바위" → 보석 다수 드롭

### 4.3 🗡️ 사냥
- **도구**: 나무칼 → 돌칼 → 철칼
- **몬스터**: 슬라임, 버섯몬, 꼬마박쥐, 불꽃몬 등 귀여운 디자인
- **연출**: 쓰러뜨리면 "뿅" 하고 아이템으로 변함 (피·잔혹 연출 없음)
- **획득**: 젤리, 깃털, 뿔, 가죽 조각
- **보스**: 지역별 1종 (왕슬라임, 돌골렘 등)
- **패배 시**: 마을로 귀환만, 아이템 손실 없음
- **협동**: 동시 접속 시 보스 체력 분담 / 협공 보너스

### 4.4 🎣 확장 활동 (MVP 이후)
- 낚시: 타이밍 탭 미니게임 + 물고기 도감
- 곤충 채집: 잠자리채 + 곤충 도감

---

## 5. 머지 시스템

- 보드 크기: 7×9 (초기), 레벨업 시 확장
- 규칙: 같은 아이템 3개 → 다음 단계 1개 (5개 합치면 2개 보너스)
- 창고의 재료를 보드로 꺼내서 사용

### 5.1 머지 체인 예시

| 계열 | 체인 |
|---|---|
| 🌲 나무 | 나뭇가지 → 통나무 → 판자 → 의자 → 소파 |
| 🪨 돌 | 돌 → 벽돌 → 돌담 → 분수 |
| 🌼 꽃 | 꽃씨 → 꽃 → 꽃다발 → 화단 |
| 🟢 젤리 | 젤리 → 젤리블록 → 젤리 램프 |
| 💎 보석 | 원석 → 보석 → 왕관/장신구 (주민 선물용) |

### 5.2 도구 제작/강화 (탐험 ↔ 머지 연결 고리)
- 나뭇가지 ×3 → 나무 곡괭이
- 돌 ×3 + 나무 곡괭이 → 돌 곡괭이 → 철 곡괭이 → 보석 곡괭이
- 칼, 바구니, 낚싯대도 동일 구조

→ 탐험을 좋아하는 사람은 **좋은 도구를 위해 머지**를, 머지를 좋아하는 사람은 **재료를 위해 탐험**을 자연스럽게 하게 됨.

---

## 6. 꾸미기 / 마을

- 섬 전체 그리드 맵에 건물·가구·길·울타리·화단 배치
- **주민**: 각 주민마다 원하는 집 조건 존재 (예: "꽃이 많은 집", "분수 근처")
- **주문 게시판**: 주민 요청 ("빨간 의자 주세요") 수행 → 하트(호감도) 획득
- **개인 방**: 가족 구성원마다 자기 방 꾸미기 (소유감)

---

## 7. 비동기 진행 장치 (한 명이 빠져도 OK)

| 장치 | 설명 |
|---|---|
| 공용 창고 | 누가 모은 재료든 한 곳에 저장, 누구나 사용 |
| 열린 퀘스트 | 가족 퀘스트는 재료만 모이면 누구든 완료 가능 |
| 주민 도우미 | 주민이 매일 소량 채집/간단 머지 대행 → 아무도 안 들어와도 섬이 조금씩 성장 |
| 동시 접속 보너스 | 2명 이상 접속 시 채집량 2배, 보스 협공, 주말 이벤트 (불꽃놀이, 낚시대회, 보물찾기) |

---

## 8. 가족 소셜 요소

- **가족 소식판**: "OO가 동굴 3층에서 보석을 찾았어요!" 자동 피드
- **선물/편지**: 오프라인 가족에게 아이템·쪽지 전송, 다음 접속 시 수령
- **기여 이름표**: 건물에 기여자 이름 표시 ("이 빵집은 OO의 돌로 지었어요")
- **도감**: 주민 / 머지 / 몬스터 / (확장) 물고기·곤충 — 처음 발견 시 소식판 알림

---

## 9. 성장 / 지역

| 마을 Lv | 해금 지역 | 주요 활동 / 콘텐츠 |
|---|---|---|
| 1~2 | 해변 · 초원 | 채집, 슬라임 |
| 3~4 | 숲 | 나무, 버섯몬, 보스: 왕슬라임 |
| 5~6 | 동굴 | 광물, 꼬마박쥐, 보스: 돌골렘 |
| 7~8 | 화산섬 | 희귀 광석, 불꽃몬 |
| 9~10 | 하늘섬 | 보석, 최종 보스 |

마을 레벨 경험치: 건물 완성, 주민 입주, 퀘스트 완료, 도감 등록

## 10. 기술 구성 (초안)

| 항목 | 선택 |
|---|---|
| 클라이언트 | HTML5 + Canvas 2D, 도트 그래픽 (세로형 모바일 우선) |
| 동기화/저장 | Firebase Realtime DB 또는 Supabase |
| 공유 상태 | 섬 배치, 공용 창고, 퀘스트, 소식판, 도감 |
| 개인 상태 | 캐릭터 위치/도구, 개인 방, 머지 보드 (개인 보드 vs 공용 보드는 검토 필요) |
| 동기화 방식 | 비동기 중심, 탐험 맵 동시 접속 시에만 실시간 위치 동기화 |
| 인증 | 가족 코드(섬 코드) + 프로필 선택 (아이 계정 없이) |

---

## 11. MVP 범위 (v0.1)

1. 지역 1개: 초원 + 작은 동굴 (2층)
2. 채집 3종(나뭇가지, 꽃, 사과), 광물 2종(돌, 석탄), 몬스터 1종(슬라임)
3. 머지 체인 3개(나무, 돌, 젤리) + 곡괭이 강화 1단계
4. 꾸미기: 건물 3종(집, 작업대, 창고) + 주민 1명 + 주문 1종
5. 공용 창고 + 가족 소식판 + Firebase 동기화

**MVP 성공 기준**: 슬라임 잡고 → 돌 캐고 → 의자 만들어서 → 첫 집을 짓는 한 바퀴를 가족 모두 각자 플레이로 완주

## 12. 검토가 필요한 열린 질문

1. 머지 보드는 **개인 보드**인가 **공용 보드**인가? (동시 편집 충돌 vs 협동감)
2. 동시 접속 시 탐험 맵 실시간 동기화 범위 (위치만? 몬스터 상태까지?)
3. 아이 나이에 따른 조작 방식 — 가상 조이스틱 vs 탭 이동 + 자동 채집
4. 주민 도우미의 자동 진행량 밸런스 (너무 많으면 플레이 동기 저하)
5. 오프라인/네트워크 끊김 시 로컬 저장 후 병합 전략
6. Firebase vs Supabase 선택 기준 (무료 티어, 실시간성, 보안 규칙)
