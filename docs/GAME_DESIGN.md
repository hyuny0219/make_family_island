# 🏝️ 가족 섬 만들기 (Make Family Island) — 게임 기획서 v0.8

> 4인 가족(부모 + 아이 2)이 함께, 또는 각자 즐기는 협동형 섬 개척 게임
> 플랫폼: 모바일 웹 (PWA, 세로 화면) · 목표 품질: **닌텐도 스타일의 완성도 높은 모바일 게임**

---

## 1. 기획 의도

| 가족 구성원 | 좋아하는 게임 | 원하는 재미 |
|---|---|---|
| 아이들 | 마인크래프트, 로블록스 | 탐험, 채광, 전투, 건축, 함께 놀기 |
| 엄마 | 모여봐요 동물의 숲, 머지 게임 | 아기자기한 꾸미기, 수집, 합치기 |
| 아빠 | (개발자) | 가족이 같이 즐기는 것 |

**핵심 원칙**
1. **역할 고정 없음** — 누구나 모든 활동을 할 수 있다. 한 명이 빠져도 진행이 멈추지 않는다.
2. **혼자 해도 진행, 같이 하면 더 즐겁게** — 협동은 보너스이지 필수 조건이 아니다.
3. **실패·페널티 없음** — 아이들이 좌절하지 않도록 잃는 것이 없다.
4. **가족의 흔적이 섬에 남는다** — 누가 무엇을 했는지 보이게 한다.

### 1.1 닌텐도 스타일 품질 원칙

| 원칙 | 구체적 기준 |
|---|---|

## 2. 컨셉 / 세계관

가족이 무인도에 표류한다. 처음엔 텐트 하나와 모닥불뿐.
섬을 탐험하며 **사냥 · 채집 · 광물 캐기**로 재료를 모으고, **머지**로 가공해 마을을 짓고, 동물 주민을 맞이해 **"우리 가족 마을"**을 완성한다.

- 시작 시 섬 이름, 가족 캐릭터(도트 아바타) 직접 설정

## 3. 핵심 루프

```
탐험 활동 (사냥·채집·채광)
      ↓
  공용 창고
      ↓
 머지로 가공 (재료 → 가구/건물 부품/도구)
      ↓
 짓기 · 꾸미기
      ↓
 주민 입주 · 마을 레벨업
      ↓
 새 지역 · 새 도구 해금 ──→ 다시 탐험
```

**화면 구성 (탭 3개, 누구나 자유 이동)**
- 🗺️ **탐험** — 탑다운 도트 맵, 활동 수행
- 🧩 **머지** — 합치기 보드
- 🏝️ **꾸미기** — 섬 전체 맵에서 배치

## 4. 탐험 활동

### 4.1 🌿 채집
- **도구**: 맨손 → 바구니(채집량 증가)
- **행동**: 나무 흔들기, 꽃 따기, 열매·버섯 줍기
- **획득**: 나뭇가지, 꽃, 꽃씨, 사과, 버섯
- **특징**: 가장 쉬운 활동. 하루 지나면 리젠

### 4.2 ⛏️ 광물 캐기
- **도구**: 나무 → 돌 → 철 → 보석 곡괭이
- **행동**: 바위/동굴 벽을 여러 번 탭해서 깨기 (도구 등급이 높을수록 탭 수 감소)
- **획득**: 돌, 석탄, 구리, 철, 보석(희귀)
- **특징**: 동굴은 층(Floor) 구조, 깊을수록 좋은 광석. 가끔 "반짝이는 바위" → 보석 다수 드롭

### 4.3 🗡️ 사냥
- **도구**: 나무칼 → 돌칼 → 철칼
- **몬스터**: 슬라임, 버섯몬, 꼬마박쥐, 불꽃몬 등 귀여운 디자인
- **연출**: 쓰러뜨리면 "뿅" 하고 아이템으로 변함 (피·잔혹 연출 없음)
- **획득**: 젤리, 깃털, 뿔, 가죽 조각
- **보스**: 지역별 1종 (왕슬라임, 돌골렘 등)
- **패배 시**: 마을로 귀환만, 아이템 손실 없음
- **협동**: 동시 접속 시 보스 체력 분담 / 협공 보너스

### 4.4 🎣 확장 활동 (MVP 이후)
- 낚시: 타이밍 탭 미니게임 + 물고기 도감
- 곤충 채집: 잠자리채 + 곤충 도감

## 5. 머지 & 제작 시스템

가공 방법은 **머지**와 **제작** 두 가지로 명확히 구분한다. 같은 재료가 두 경로에 모두 쓰일 수 있지만, **어느 화면에서 쓰느냐**로 결과가 정해지므로 입력이 같아도 결과가 모호하지 않다.

| 구분 | 머지 (🧩 머지 탭) | 제작 (🔨 작업대) |
|---|---|---|
| 입력 | **같은** 아이템 3개 (또는 5개) | 레시피에 정해진 **서로 다른** 재료 조합 |
| 결과 | 같은 계열의 **다음 단계** 1개 | 레시피 결과물 (도구, 특수 아이템) |
| 조작 | 보드에서 드래그해서 겹치기 | 작업대에서 레시피 선택 → "만들기" 버튼 |
| 재료 위치 | 창고 → 보드로 꺼낸 아이템 | 창고에서 바로 차감 (보드 아이템 사용 안 함) |
| 예 | 나뭇가지 ×3 → 통나무 | 레시피 "나무 곡괭이" (나뭇가지 ×3) |

### 5.0 머지 규칙
- 보드 크기: 7×9 (초기), 레벨업 시 확장
- 규칙: 같은 아이템 3개 → 다음 단계 1개 (5개 합치면 2개 보너스)
- 보드 위에서는 **항상 체인의 다음 단계만** 나온다. 도구는 머지로 절대 나오지 않는다.
- 창고의 재료를 보드로 꺼내서 사용

### 5.1 머지 체인 예시

| 계열 | 체인 |
|---|---|
| 🌲 나무 | 나뭇가지 → 통나무 → 판자 → 의자 → 소파 |
| 🪨 돌 | 돌 → 벽돌 → 돌담 → 분수 |
| 🌼 꽃 | 꽃씨 → 꽃 → 꽃다발 → 화단 |
| 🟢 젤리 | 젤리 → 젤리블록 → 젤리 램프 |
| 💎 보석 | 원석 → 보석 → 왕관/장신구 (주민 선물용) |

### 5.2 도구 제작/강화 — 🔨 작업대 레시피 (탐험 ↔ 머지 연결 고리)

도구는 **작업대 제작으로만** 만든다. 상위 도구 레시피에는 **머지로 만든 중간 재료**가 들어가서, 탐험과 머지가 자연스럽게 연결된다.

| 레시피 | 재료 | 비고 |
|---|---|---|
| 나무 곡괭이 / 나무칼 | 나뭇가지 ×3 | **시작 시 1개씩 지급** (채광·사냥을 처음부터 가능하게) |
| 돌 곡괭이 / 돌칼 | 나무 곡괭이(칼) + **판자** ×1 + 돌 ×3 | 판자 = 머지 산출물 |
| 철 곡괭이 / 철칼 | 돌 곡괭이(칼) + **벽돌** ×2 + 철 ×3 | 벽돌 = 머지 산출물 |
| 보석 곡괭이 | 철 곡괭이 + 보석 ×1 + 철 ×3 | |
| 바구니 | 나뭇가지 ×2 + 꽃 ×2 | |

- 강화 레시피는 하위 도구를 재료로 소모 (업그레이드 개념)
- 칼, 낚싯대도 같은 구조

→ 탐험을 좋아하는 사람은 **좋은 도구에 필요한 판자·벽돌 때문에 머지**를, 머지를 좋아하는 사람은 **재료를 위해 탐험**을 자연스럽게 하게 됨.

## 5A. 구현된 머지·작업대 (v0.6)

**머지 보드** (개인, 6×6, 이 기기에 저장)
- 아래 "창고에서 꺼내기"에서 재료를 톡 → 보드에 놓임 (같은 것과 이어지는 칸을 자동으로 골라, 톡톡톡 3번이면 저절로 합체)
- 같은 것 3개가 상하좌우로 붙으면 다음 단계 1개, **5개면 2개**. 남는 것은 사라지지 않고 그 자리에 남는다 (4개 → 1개 + 1개 남음, 6개 → 2개 + 1개 남음). 연쇄 합체 가능
- 끌어서 옮기기/자리 바꾸기, 톡 누르거나 보드 밖으로 끌면 창고로, "모두 창고로" 버튼
- 처음 만든 물건은 "✨ 새로운 발견!" 축하 + 도감 등록

| 체인 | 단계 |
|---|---|
| 🌲 나무 | 나뭇가지 → 통나무 → 판자 → 의자 → 소파 |
| 🪨 돌 | 돌 → 벽돌 → 돌담 → 분수 |
| 🌼 꽃 | 꽃 → 꽃다발 → 화분 → 꽃 아치 |
| 🍊 과일 | 과일 → 주스 → 잼 → 파이 |
| 🐚 조개 | 조개껍데기 → 진주 → 진주 목걸이 |
| 🌰 솔방울 | 솔방울 → 리스 |
| ⚫ 석탄 | 석탄 → 등불 |

**작업대** (`src/data/merge.ts`의 RECIPES)

| 만들 것 | 재료 | 효과 |
|---|---|---|
| 바구니 (도구) | 나뭇가지 2 + 꽃 2 | 나무·덤불에서 60% 확률로 하나 더 |
| 낚싯대 (도구) | 통나무 1 + 나뭇가지 3 | 입질 시간 1.4초 → 2.2초, 장화 안 나옴, 황금 물고기 3배 |
| 돌 곡괭이 (도구) | 판자 1 + 돌 3 | 큰 바위 캐기 가능, 돌 캐는 속도 2배 |
| 울타리 / 탁자 / 침대 | 통나무·판자·꽃다발 조합 | 꾸미기(M4)에서 사용 |

## 6. 꾸미기 / 마을

- 섬 전체 그리드 맵에 건물·가구·길·울타리·화단 배치
- **주민**: 각 주민마다 원하는 집 조건 존재 (예: "꽃이 많은 집", "분수 근처")
- **주문 게시판**: 주민 요청 ("빨간 의자 주세요") 수행 → 하트(호감도) 획득
- **개인 방**: 가족 구성원마다 자기 방 꾸미기 (소유감)

## 6A. 구현된 꾸미기·주민 (v0.7)

**꾸미기 탭** — 섬 화면 그대로, 아래에 놓을 물건 줄이 생긴다
- 물건을 고르고 땅을 톡 → 그 칸에 놓임. 놓인 칸을 다시 톡 하면 창고로 돌아옴 (칸 기준 판정이라 울타리를 나란히 놓기 쉬움)
- 열린 지역의 빈 땅에만 놓을 수 있음 (바다·나무·바위·선착장·곰이 서 있는 칸 제외). 돌담·울타리·분수는 지나갈 수 없음
- 섬마다 따로 저장, **마을 점수**는 모든 섬 합계

| 물건 | 점수 | 물건 | 점수 |
|---|---|---|---|
| 울타리 | 2 | 나무 침대 | 5 |
| 의자·돌담·등불·리스 | 3 | 소파 | 6 |
| 화분·탁자 | 4 | 분수·꽃 아치 | 8 |
| | | 황금 트로피 | 10 |

**동물 주민** — 마을 점수가 오르면 차례로 이사 온다 (한 번 오면 떠나지 않음)

| 주민 | 필요 점수 |
|---|---|
| 🐰 토토 (토끼) | 6 |
| 🐱 나비 (고양이) | 16 |
| 🦊 여울 (여우) | 30 |
| 🐧 펭이 (펭귄) | 50 |

- 주민은 캠프 근처를 돌아다니고, 누르면 다가가서 **부탁**을 듣는다 ("송사리 4개만 가져다줄래요?")
- 들어주면 호감도 +1, 선물(보석 원석·석탄·큰 물고기·불가사리·판자·진주 중 1~2개), 60초 뒤 새 부탁
- 호감도 2부터는 머지로 만든 물건도 부탁, **호감도 5가 되면 황금 트로피** 선물 (놓으면 마을 점수 10)
- 정의: `src/data/village.ts`, 상태: `src/state/village.ts`

- 정의: `src/data/islands.ts`

### 9.2 지역 (자동 생성)
섬마다 300~500개 지역을 손으로 만들 수 없으므로 **시드 기반 자동 생성** (`src/world/generate.ts`). 같은 섬은 항상 같은 모양.
1. 섬 모양(해안선 굴곡) → 2. 지역 씨앗을 고르게 퍼뜨림(0번은 남쪽 해안 = 배로 도착하는 곳) → 3. 타일별 가장 가까운 씨앗 지역(경계는 구불구불)
4. 땅으로 이어진 지역끼리 그래프 → 도착 캠프에서의 거리(깊이)와 부모 지역 결정
5. 지역 분위기 배정 (과수원·숲·바위 언덕·꽃밭·해변, 가까운 지역부터 모든 분위기가 한 번씩)
6. 분위기별 오브젝트·연못·낚시터 배치

### 9.3 지역 해금 퀘스트
- 잠긴 지역은 **구름**으로 덮여 있음. **부모 지역이 열린 지역만** 열 수 있고, 경계에 **❗표지판**이 생김
- 표지판(또는 구름)을 누르면 퀘스트: 필요한 재료를 모아 "길 열기!" → 구름이 걷히는 연출
- 재료는 **이미 열린 조상 지역에서 구할 수 있는 것만** 요구 → 항상 깰 수 있음
- 양 = 7 + 깊이×2.4 + 섬번호×3.5 (최대 60), 물고기·석탄·불가사리는 절반. 재료 종류는 캠프 바로 옆만 2종, 그 밖은 3종
- **머지 물건 요구**: 캠프에서 3칸 이상(2번 섬부터는 2칸 이상) 떨어진 지역은 한 번 합친 물건(통나무·벽돌·꽃다발·주스·진주·리스) 1개 이상, 거기서 4칸 더 먼 지역은 두 번 합친 물건(판자·돌담·화분·잼·목걸이)까지
- 분위기별 재료: 과수원(과일·나뭇가지), 숲(나뭇가지·솔방울), 바위(돌·석탄), 꽃밭(꽃·나뭇가지), 해변(조개·불가사리·돌), 물가(물고기)

### 9.4 낚시
- 열린 지역의 물가에 물결이 이는 **낚시터**가 있음 → 누르면 물가로 걸어가 찌를 던짐
- 1.6~4초 기다리면 **❗**가 뜨고 찌가 쑥 → 1.4초 안에 화면을 톡 (아이도 할 수 있게 넉넉히)
- 너무 빨리 누르면 "너무 빨랐어요", 늦으면 "도망갔어요" — 잃는 건 없음
- 분위기별 어종: 송사리·붕어·큰 물고기·황금 물고기(희귀)·꽃게·조개·낡은 장화(꽝)
- 잡은 낚시터는 40초 쉬었다가 다시 생김

### 9.5 배 만들기 → 다른 섬으로
- 도착 캠프 아래 **선착장**(옆에 재료 상자·등대)을 누르면 배 만들기
- 배 재료 (섬 번호 i): **판자 3+i**, 돌 10+4i, 솔방울 6+3i, 조개 5+2i, 붕어 3+i
- 배가 완성되면 선착장에 배가 떠 있고, 누르면 **섬 목록** → 가 본 섬끼리는 자유롭게 오감
- 출발 연출: 곰이 배에 타고 오른쪽으로 떠난 뒤 화면 전환
- 창고(재료)는 모든 섬이 공유, 지역 진행은 섬마다 저장

## 10A. 개발 흐름 (모바일 전용 환경)

개발자(아빠)는 **폰만으로** 개발을 진행한다.

1. 채팅으로 기능 요청
2. Claude가 코드 작성 → 모바일 뷰포트에서 자동 확인(스크린샷) → PR 생성
3. GitHub Actions가 PR 미리보기를 `/pr-preview/pr-<번호>/`에 자동 배포하고 PR에 링크 댓글
4. 폰에서 링크를 열어 테스트, 가족에게 바로 보여주기
5. 필요 시 Codex 리뷰 → 아빠가 PR 머지 → 정식 주소 자동 반영

## 10B. 아트·사운드 파이프라인

### 확정된 아트 방향 (v0.3)
- **그림체**: 납작하고 부드러운 파스텔 도트, 큼직한 픽셀, 완전한 탑다운 바닥 + 3/4 시점 오브젝트 (`art/source/style_reference.png`)
- **캐릭터**: **곰 가족** — 아빠 곰(파란 스카프), 엄마 곰(꽃 핀), 첫째 곰(초록 가방), 막내 곰(크림색, 노란 모자). 시작 화면에서 누구로 놀지 선택
- **도구**: Higgsfield의 **GPT Image 2.6** + 스타일 레퍼런스 이미지 (Z Image로 만든 그림체를 레퍼런스로 넣어 그림체는 유지하고 구성 지시는 정확히 따르게 함)
  - 모델 비교 결과: GPT Image 2.6이 프롬프트(격자·개수·방향)를 가장 정확히 따름, Z Image는 그림체가 게임 화면에 가장 잘 맞음, Recraft V4.1은 둘 다 중간

| 단계 | 방법 |
|---|---|
| 시트 생성 | 레퍼런스 + 격자 지시(예: 4행×3열), 캐릭터·오브젝트는 투명 배경 |
| 후처리 | `scripts/process_art.py` — 칸별 자르기 → 가장 큰 덩어리만 남기기(이웃 칸 조각 제거) → 1/6 축소 → 알파 이진화. 타일은 칸 중앙만 잘라 24×24 + 1px extrude |
| 규격 | 타일 24×24, 곰 약 26~36px 높이, 나무 약 40px |
| 원본 보관 | `art/source/*.png` (재생성·재처리 가능하도록) |
| 사운드 | 지금은 WebAudio 임시 효과음, 출시 전 교체 검토 |

AI 생성 이미지는 장마다 그리드·팔레트가 흔들리기 쉬우므로, **같은 레퍼런스로 시트 단위 생성 + 후처리 스크립트로 규격 강제**를 원칙으로 한다.

## 11. MVP 범위 (v0.1)

1. 지역 1개: 초원 + 작은 동굴 (2층)
2. 채집 3종(나뭇가지, 꽃, 사과), 광물 2종(돌, 석탄), 몬스터 1종(슬라임)

4. 작업대 제작: 시작 도구(나무 곡괭이·나무칼) 지급 + 레시피 2개(돌 곡괭이, 돌칼)
5. 꾸미기: 건물 3종(집, 작업대, 창고) + 주민 1명 + 주문 1종
6. 공용 창고 + 가족 소식판 + Firebase 동기화

**MVP 성공 기준**: 슬라임 잡고 → 돌 캐고 → 의자 만들어서 → 첫 집을 짓는 한 바퀴를 가족 모두 각자 플레이로 완주
