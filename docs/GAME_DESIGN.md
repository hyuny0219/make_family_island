# 🏝️ 가족 섬 만들기 (Make Family Island) — 게임 기획서 v0.2

> 4인 가족(부모 + 아이 2)이 함께, 또는 각자 즐기는 협동형 섬 개척 게임
> 플랫폼: 모바일 웹 (PWA, 세로 화면) · 목표 품질: **닌텐도 스타일의 완성도 높은 모바일 게임**

---

## 1. 기획 의도

| 가족 구성원 | 좋아하는 게임 | 원하는 재미 |
|---|---|---|
| 아이들 | 마인크래프트, 로블록스 | 탐험, 채광, 전투, 건축, 함께 놀기 |
| 엄마 | 모여봐요 동물의 숲, 머지 게임 | 아기자기한 꾸미기, 수집, 합치기 |
| 아빠 | (개발자) | 가족이 같이 즐기는 것 |

**핵심 원칙**
1. **역할 고정 없음** — 누구나 모든 활동을 할 수 있다. 한 명이 빠져도 진행이 멈추지 않는다.
2. **혼자 해도 진행, 같이 하면 더 즐겁게** — 협동은 보너스이지 필수 조건이 아니다.
3. **실패·페널티 없음** — 아이들이 좌절하지 않도록 잃는 것이 없다.
4. **가족의 흔적이 섬에 남는다** — 누가 무엇을 했는지 보이게 한다.

### 1.1 닌텐도 스타일 품질 원칙

| 원칙 | 구체적 기준 |
|---|---|
| **손맛 (Juice)** | 모든 터치에 반응: 흔들림, 찌그러짐(squash & stretch), 파티클, 효과음, (안드로이드) 진동. 아이템 획득 시 튀어올라 인벤토리로 날아감 |
| **설명 없이 배우기** | 긴 텍스트 튜토리얼 금지. 첫 5분 안에 캐기 → 합치기 → 짓기를 자연스럽게 1회 경험하도록 맵·퀘스트 배치 |
| **살아있는 캐릭터** | 주민은 대사·감정 표현·하루 일과를 가짐. 플레이어 행동에 반응 |
| **수집 욕구** | 도감, 희귀 아이템, 계절 한정 아이템 |
| **시간과 계절** | 실제 시간 연동 아침/밤, 사계절, 명절 이벤트 |
| **아이도 쓰는 UI** | 큰 버튼(최소 48px 터치 영역), 아이콘 중심, 글을 못 읽어도 플레이 가능 |
| **착한 과금** | 광고·확률형 뽑기 없음. (출시 시) 유료 구매 1회 또는 확장팩 |
| **60fps** | 중급 안드로이드 폰에서도 60fps 유지가 기준 |

## 2. 컨셉 / 세계관

가족이 무인도에 표류한다. 처음엔 텐트 하나와 모닥불뿐.
섬을 탐험하며 **사냥 · 채집 · 광물 캐기**로 재료를 모으고, **머지**로 가공해 마을을 짓고, 동물 주민을 맞이해 **"우리 가족 마을"**을 완성한다.

- 시작 시 섬 이름, 가족 캐릭터(도트 아바타) 직접 설정

## 3. 핵심 루프

```
탐험 활동 (사냥·채집·채광)
      ↓
  공용 창고
      ↓
 머지로 가공 (재료 → 가구/건물 부품/도구)
      ↓
 짓기 · 꾸미기
      ↓
 주민 입주 · 마을 레벨업
      ↓
 새 지역 · 새 도구 해금 ──→ 다시 탐험
```

**화면 구성 (탭 3개, 누구나 자유 이동)**
- 🗺️ **탐험** — 탑다운 도트 맵, 활동 수행
- 🧩 **머지** — 합치기 보드
- 🏝️ **꾸미기** — 섬 전체 맵에서 배치

## 4. 탐험 활동

### 4.1 🌿 채집
- **도구**: 맨손 → 바구니(채집량 증가)
- **행동**: 나무 흔들기, 꽃 따기, 열매·버섯 줍기
- **획득**: 나뭇가지, 꽃, 꽃씨, 사과, 버섯
- **특징**: 가장 쉬운 활동. 하루 지나면 리젠

### 4.2 ⛏️ 광물 캐기
- **도구**: 나무 → 돌 → 철 → 보석 곡괭이
- **행동**: 바위/동굴 벽을 여러 번 탭해서 깨기 (도구 등급이 높을수록 탭 수 감소)
- **획득**: 돌, 석탄, 구리, 철, 보석(희귀)
- **특징**: 동굴은 층(Floor) 구조, 깊을수록 좋은 광석. 가끔 "반짝이는 바위" → 보석 다수 드롭

### 4.3 🗡️ 사냥
- **도구**: 나무칼 → 돌칼 → 철칼
- **몬스터**: 슬라임, 버섯몬, 꼬마박쥐, 불꽃몬 등 귀여운 디자인
- **연출**: 쓰러뜨리면 "뿅" 하고 아이템으로 변함 (피·잔혹 연출 없음)
- **획득**: 젤리, 깃털, 뿔, 가죽 조각
- **보스**: 지역별 1종 (왕슬라임, 돌골렘 등)
- **패배 시**: 마을로 귀환만, 아이템 손실 없음
- **협동**: 동시 접속 시 보스 체력 분담 / 협공 보너스

### 4.4 🎣 확장 활동 (MVP 이후)
- 낚시: 타이밍 탭 미니게임 + 물고기 도감
- 곤충 채집: 잠자리채 + 곤충 도감

## 5. 머지 & 제작 시스템

가공 방법은 **머지**와 **제작** 두 가지로 명확히 구분한다. 같은 재료가 두 경로에 모두 쓰일 수 있지만, **어느 화면에서 쓰느냐**로 결과가 정해지므로 입력이 같아도 결과가 모호하지 않다.

| 구분 | 머지 (🧩 머지 탭) | 제작 (🔨 작업대) |
|---|---|---|
| 입력 | **같은** 아이템 3개 (또는 5개) | 레시피에 정해진 **서로 다른** 재료 조합 |
| 결과 | 같은 계열의 **다음 단계** 1개 | 레시피 결과물 (도구, 특수 아이템) |
| 조작 | 보드에서 드래그해서 겹치기 | 작업대에서 레시피 선택 → "만들기" 버튼 |
| 재료 위치 | 창고 → 보드로 꺼낸 아이템 | 창고에서 바로 차감 (보드 아이템 사용 안 함) |
| 예 | 나뭇가지 ×3 → 통나무 | 레시피 "나무 곡괭이" (나뭇가지 ×3) |

### 5.0 머지 규칙
- 보드 크기: 7×9 (초기), 레벨업 시 확장
- 규칙: 같은 아이템 3개 → 다음 단계 1개 (5개 합치면 2개 보너스)
- 보드 위에서는 **항상 체인의 다음 단계만** 나온다. 도구는 머지로 절대 나오지 않는다.
- 창고의 재료를 보드로 꺼내서 사용

### 5.1 머지 체인 예시

| 계열 | 체인 |
|---|---|
| 🌲 나무 | 나뭇가지 → 통나무 → 판자 → 의자 → 소파 |
| 🪨 돌 | 돌 → 벽돌 → 돌담 → 분수 |
| 🌼 꽃 | 꽃씨 → 꽃 → 꽃다발 → 화단 |
| 🟢 젤리 | 젤리 → 젤리블록 → 젤리 램프 |
| 💎 보석 | 원석 → 보석 → 왕관/장신구 (주민 선물용) |

### 5.2 도구 제작/강화 — 🔨 작업대 레시피 (탐험 ↔ 머지 연결 고리)

도구는 **작업대 제작으로만** 만든다. 상위 도구 레시피에는 **머지로 만든 중간 재료**가 들어가서, 탐험과 머지가 자연스럽게 연결된다.

| 레시피 | 재료 | 비고 |
|---|---|---|
| 나무 곡괭이 / 나무칼 | 나뭇가지 ×3 | **시작 시 1개씩 지급** (채광·사냥을 처음부터 가능하게) |
| 돌 곡괭이 / 돌칼 | 나무 곡괭이(칼) + **판자** ×1 + 돌 ×3 | 판자 = 머지 산출물 |
| 철 곡괭이 / 철칼 | 돌 곡괭이(칼) + **벽돌** ×2 + 철 ×3 | 벽돌 = 머지 산출물 |
| 보석 곡괭이 | 철 곡괭이 + 보석 ×1 + 철 ×3 | |
| 바구니 | 나뭇가지 ×2 + 꽃 ×2 | |

- 강화 레시피는 하위 도구를 재료로 소모 (업그레이드 개념)
- 칼, 낚싯대도 같은 구조

→ 탐험을 좋아하는 사람은 **좋은 도구에 필요한 판자·벽돌 때문에 머지**를, 머지를 좋아하는 사람은 **재료를 위해 탐험**을 자연스럽게 하게 됨.

## 6. 꾸미기 / 마을

- 섬 전체 그리드 맵에 건물·가구·길·울타리·화단 배치
- **주민**: 각 주민마다 원하는 집 조건 존재 (예: "꽃이 많은 집", "분수 근처")
- **주문 게시판**: 주민 요청 ("빨간 의자 주세요") 수행 → 하트(호감도) 획득
- **개인 방**: 가족 구성원마다 자기 방 꾸미기 (소유감)

## 7. 비동기 진행 장치 (한 명이 빠져도 OK)

| 장치 | 설명 |
|---|---|
| 공용 창고 | 누가 모은 재료든 한 곳에 저장, 누구나 사용 |

| 주민 도우미 | 주민이 매일 소량 채집/간단 머지 대행 → 아무도 안 들어와도 섬이 조금씩 성장 |
| 동시 접속 보너스 | 2명 이상 접속 시 채집량 2배, 보스 협공, 주말 이벤트 (불꽃놀이, 낚시대회, 보물찾기) |

## 10. 기술 구성

### 10.1 스택

| 항목 | 선택 | 비고 |
|---|---|---|
| 게임 엔진 | **Phaser 3 + TypeScript** | 트윈·파티클·카메라 연출 내장 → 손맛 구현 |
| 빌드 | Vite | |
| 앱화 | **PWA** | 홈 화면 추가, 전체화면, 오프라인 실행 |
| 화면 | 세로 고정, 논리 해상도 360×640, `Scale.FIT` + 픽셀아트 렌더링 | |
| 저장 | 로컬 우선 (localStorage → 추후 IndexedDB) | 네트워크 없어도 플레이 |
| 동기화 | Firebase (M5에서 도입) | 공용 창고는 증감(increment)만 사용해 충돌 방지 |
| 배포 | GitHub Pages + GitHub Actions | main → 정식 주소, PR → 미리보기 주소 |
| 스토어 출시 (선택) | Capacitor로 래핑 | 코드 그대로 iOS/Android 앱 |

### 10.2 상태 구분

| 구분 | 내용 |
|---|---|
| 공유 상태 | 섬 배치, 공용 창고, 퀘스트, 소식판, 도감 |
| 개인 상태 | 캐릭터 위치/도구, 개인 방, **머지 보드 (개인 보드로 결정)** |
| 동기화 방식 | 비동기 중심, 탐험 맵 동시 접속 시에만 실시간 위치 동기화 |
| 인증 | 가족 코드(섬 코드) + 프로필 선택 (아이 계정 없이) |

### 10.3 데이터 주도 설계
아이템, 머지 체인, 레시피, 몬스터, 주민, 지역은 모두 `src/data/*.ts`(또는 JSON)로 분리한다. 밸런스 조정 시 게임 로직 코드를 수정하지 않는다.

## 10A. 개발 흐름 (모바일 전용 환경)

개발자(아빠)는 **폰만으로** 개발을 진행한다.

1. 채팅으로 기능 요청
2. Claude가 코드 작성 → 모바일 뷰포트에서 자동 확인(스크린샷) → PR 생성
3. GitHub Actions가 PR 미리보기를 `/pr-preview/pr-<번호>/`에 자동 배포하고 PR에 링크 댓글
4. 폰에서 링크를 열어 테스트, 가족에게 바로 보여주기
5. 필요 시 Codex 리뷰 → 아빠가 PR 머지 → 정식 주소 자동 반영

## 10B. 아트·사운드 파이프라인

| 단계 | 방법 |
|---|---|
| 개발 중 | 코드로 그린 임시 도형/도트 (플레이스홀더) |
| 스타일 확정 | Higgsfield / GPT 이미지 생성으로 콘셉트 아트·스타일 가이드 비교 후 선택 |
| 실제 스프라이트 | 생성 이미지 → 다운스케일 + 팔레트 고정(양자화) + 투명 배경 정리 → 스프라이트 시트 |
| 기준 | 타일 16×16 / 캐릭터 16×24, 팔레트 32색 이내, 외곽선 규칙 통일 |
| 사운드 | 무료(CC0) 효과음으로 시작, 출시 전 교체 검토 |

AI 생성 이미지는 장마다 그리드·팔레트가 흔들리기 쉬우므로, **후처리 스크립트로 규격을 강제**하고 한 번에 같은 시트 단위로 생성한다.

## 11. MVP 범위 (v0.1)

1. 지역 1개: 초원 + 작은 동굴 (2층)
2. 채집 3종(나뭇가지, 꽃, 사과), 광물 2종(돌, 석탄), 몬스터 1종(슬라임)
3. 머지 체인 3개(나무, 돌, 젤리)
4. 작업대 제작: 시작 도구(나무 곡괭이·나무칼) 지급 + 레시피 2개(돌 곡괭이, 돌칼)
5. 꾸미기: 건물 3종(집, 작업대, 창고) + 주민 1명 + 주문 1종
6. 공용 창고 + 가족 소식판 + Firebase 동기화

**MVP 성공 기준**: 슬라임 잡고 → 돌 캐고 → 의자 만들어서 → 첫 집을 짓는 한 바퀴를 가족 모두 각자 플레이로 완주
